# Contributing to WindFieldUnity

Thanks for your interest in improving `WindFieldUnity`.

## How to contribute

1. Fork the repository and create a topic branch.
2. Keep source file encodings consistent (see `docs/06-notes.md`).
3. Do not reintroduce any third-party branding; keep all attribution as **Felix**.
4. Add or update documentation for any behavior change.
5. Open a Pull Request describing the change and how you verified it.

## Reporting issues

Please include your OS, toolchain version, hardware model (if any), and a
minimal reproduction.  Issues and PRs are welcome.

## Code of conduct

Be respectful and constructive.  By participating you agree to keep discussions
technical and welcoming.
